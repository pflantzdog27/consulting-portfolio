**Experience Level:** Expert (4+ years since launch)

Employee Center is ServiceNow's modern, consumer-grade user interface built on the UI Builder framework. We specialize in:

- **Workspace Creation:** Designing and building custom workspaces for different user personas and workflows
- **Page Design:** Creating intuitive layouts using UI Builder's drag-and-drop interface
- **Component Development:** Building custom components when out-of-box options don't meet needs
- **Search Optimization:** Implementing and tuning AI-powered search for better discoverability
- **Mobile Optimization:** Ensuring seamless experiences across all device types
- **Role-Based Personalization:** Tailoring landing pages and content based on user roles
- **Analytics Integration:** Implementing usage tracking and performance monitoring
- **Migration from Service Portal:** Planning and executing transitions from legacy portals

**Key Capabilities:**
- UI Builder advanced configuration

#### Service Portal
**Experience Level:** Expert (8+ years)

Service Portal is ServiceNow's Angular-based portal framework. Despite Employee Center being the modern direction, Service Portal remains critical for many implementations:

- **Custom Widget Development:** Building complex, reusable Angular widgets
- **Theme Development:** Creating custom themes and branding
- **Performance Optimization:** Reducing load times through lazy loading, caching, and query optimization
- **Client Scripts:** Writing efficient client-side JavaScript for dynamic forms
- **Server Scripts:** Building robust server-side logic for widget data providers
- **CSS/SCSS Styling:** Advanced styling and responsive design
- **Third-Party Integration:** Integrating external libraries and APIs
- **Migration Strategies:** Planning transitions to Employee Center when appropriate

**Technologies Used:**
- AngularJS 1.5+
- Bootstrap 3/4
- JavaScript (ES5/ES6)
- jQuery
- SASS/SCSS
- GlideAjax
